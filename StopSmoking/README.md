# StopSmoking

Small front-end project demonstrating charts and UI for tracking a quit-smoking plan.

How to use
- Initialize a git repo and commit (already done locally):

  git init
  git add .
  git commit -m "Initial commit: StopSmoking project"

To connect to a remote (GitHub):

  git remote add origin <your-remote-url>
  git push -u origin main
